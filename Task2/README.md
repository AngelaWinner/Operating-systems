# Лабораторная работа №2: Работа с потоками в C++

## Описание проекта

Проект реализует многопоточную обработку целочисленного массива на платформе Windows с использованием различных стандартов C++. Программа создает три потока: основной поток `main` и два рабочих потока `min_max` и `average`, которые параллельно вычисляют минимальное/максимальное значение и среднее арифметическое элементов массива соответственно.

## Задание лабораторной работы

### Цель
Реализация многопоточной обработки массива с использованием Windows API потоков и стандартных потоков C++.

### Требования к программе:
1. **Основной поток (main)**:
   - Создание массива целых чисел (размер и элементы вводятся пользователем)
   - Создание потоков `min_max` и `average`
   - Ожидание завершения рабочих потоков
   - Замена минимального и максимального элементов на среднее значение
   - Вывод модифицированного массива

2. **Поток `min_max`**:
   - Поиск минимального и максимального элементов массива
   - Вывод найденных значений на консоль
   - Задержка 7 мс после каждого сравнения

3. **Поток `average`**:
   - Вычисление среднего арифметического элементов массива
   - Вывод результата на консоль
   - Задержка 12 мс после каждого суммирования

## Реализации

### 1. Task2.cpp (Windows API)
**Особенности**:
- Использование Windows API (`CreateThread`, `Sleep`, `WaitForSingleObject`)
- Глобальные переменные для обмена данными между потоками
- Целочисленное вычисление среднего значения

### 2. Task2-C++11.cpp (C++11 std::thread)
**Особенности**:
- Использование стандарта C++11
- Использование `std::thread`, `std::this_thread::sleep_for`
- Валидация ввода через регулярные выражения
- Работа с `std::vector` вместо сырых массивов
- Более корректное вычисление среднего (double)

### 3. Task2-C++98.cpp (C++98 совместимость)
**Особенности**:
- Поддержка стандарта C++98
- Более безопасная обработка ввода
- Использование Windows API потоков
- Приведение типов в стиле C

## Модульное тестирование

Файл `UnitTest.cpp` содержит тесты для проверки корректности работы функций из `Functions.cpp`:

1. **testMethod1**: Проверка поиска min/max в обычном массиве
2. **testMethod2**: Проверка с отрицательными числами
3. **testMethod3**: Проверка с одинаковыми элементами
4. **testMethod4**: Проверка вычисления среднего
5. **testMethod5**: Проверка вычисления среднего с большими числами

## Особенности реализации

1. **Синхронизация**: Использование `WaitForSingleObject` для ожидания завершения потоков
2. **Задержки**: Имитация вычислений через `Sleep()` (7 мс для min_max, 12 мс для average)
3. **Безопасность**: Проверка успешности создания потоков
4. **Освобождение ресурсов**: Корректное закрытие хэндлов потоков и освобождение памяти

## Технические требования

- **Операционная система**: Windows (для Windows API версий)
- **Компилятор**: Поддерживающий C++98, C++11 или Windows API
- **Библиотеки**: Windows.h (для API версий), стандартная библиотека C++

## Примечания

1. Все версии программы выполняют одинаковую функциональность
2. C++11 версия имеет более современный и безопасный код
3. Windows API версии предназначены для изучения низкоуровневых механизмов потоков
4. В вычислении среднего есть особенности: в Task2.cpp используется целочисленное деление, в других - более точное вычисление
