# Лабораторная работа №3: Синхронизация потоков (CMake версия)

## Описание проекта

Проект представляет собой многопоточное консольное приложение на C++ для изучения механизмов синхронизации потоков. Программа реализует модель управления несколькими рабочими потоками (marker), которые конкурируют за доступ к общему массиву. Эта версия проекта включает поддержку системы сборки CMake.

## Задание лабораторной работы

### Цель
Изучение механизмов синхронизации потоков с использованием критических секций и событий.

### Требования:

1. **Основной поток (main)**:
   - Создание массива целых чисел заданного размера
   - Инициализация массива нулями
   - Запуск N потоков marker с уникальными идентификаторами
   - Ожидание сигналов от потоков о блокировке
   - Интерактивное управление потоками (выбор потока для завершения)
   - Отображение состояния массива на каждом этапе

2. **Поток marker**:
   - Маркировка случайных элементов массива своим ID
   - При обнаружении занятой ячейки - уведомление main
   - Ожидание команд от main (продолжить/завершиться)
   - При завершении - обнуление всех помеченных элементов

## Механизмы синхронизации

1. **Мьютексы (std::mutex)**: Защита критических секций при доступе к общему массиву
2. **Условные переменные (std::condition_variable)**: Сигнализация между потоками
3. **Флаги состояний**: Управление жизненным циклом потоков (ожидание, продолжение, завершение)
4. **RAII-идиома**: Автоматическое управление ресурсами через `std::unique_lock`

## Алгоритм работы

### Фаза 1: Инициализация
1. Пользователь задает размер массива и количество потоков
2. Массив инициализируется нулями
3. Создаются потоки marker с уникальными идентификаторами

### Фаза 2: Работа потоков
1. Каждый поток пытается пометить случайные элементы массива
2. При успехе: ставит свой ID, пауза 5 мс
3. При неудаче (элемент уже занят): сообщает main и ждет команды

### Фаза 3: Управление
1. Когда все потоки заблокированы, main выводит состояние массива
2. Пользователь выбирает поток для завершения
3. Выбранный поток обнуляет свои метки и завершается
4. Оставшиеся потоки возобновляют работу

### Фаза 4: Завершение
Процесс повторяется до завершения всех потоков

## Технические особенности

### CMake конфигурация:
- Минимальная версия CMake: 3.8
- Стандарт C++: C++20
- Автоматическая настройка формата отладочной информации

### Ключевые функции:
- **marker()**: Функция потока marker с логикой маркировки
- **Структура markerThreadParams**: Параметры для создания потоков
- **Векторы управления**: threadCVs, threadReadyFlags, continueFlags, closeThreadFlags

## Требования к системе

### Для сборки:
- CMake версии 3.8 или выше
- Компилятор C++ с поддержкой C++20
- Windows (для использования Windows.h) или кроссплатформенный компилятор

## Особенности реализации

1. **Потокобезопасность**: Все операции с общим массивом защищены мьютексами
2. **Корректное завершение**: Динамическая память освобождается, все потоки корректно завершаются
3. **Валидация ввода**: Проверка корректности пользовательского ввода
4. **Предсказуемая генерация**: Использование srand() с уникальными seed для каждого потока
5. **Интерактивность**: Возможность управления потоками в реальном времени

## Примечания

1. Паузы в 5 миллисекунд имитируют время обработки данных
2. Программа демонстрирует типичные проблемы синхронизации и их решение
3. Алгоритм гарантирует завершение всех потоков в конечном счете
4. Реализация устойчива к некорректному вводу пользователя
5. CMake обеспечивает переносимость проекта между различными средами разработки
